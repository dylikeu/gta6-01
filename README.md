SOLMAR — Streets of Solmar: an original 2D top-down open-world crime game in a fictional sun-soaked coastal city. Explore on foot and by car, steal cars, dodge or outrun the police across a 0–5 star wanted system, take on 6 story missions for Rosa Delgado against the Los Tiburones gang, fight with pistol and shotgun, earn cash from taxi fares and 12 hidden packages, and save your progress. Pure canvas 2D and synthesized WebAudio sound — no libraries, no network, no assets from any other game. Keyboard + mouse, offline in a desktop browser.

## Run it

```sh
node serve.ts
```
